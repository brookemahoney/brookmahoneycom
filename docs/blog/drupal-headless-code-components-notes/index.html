Drupal Headless Code Components Notes

Overview

This document is an overview of my current local setup for working with Drupal Code Components and headless Next.js.

See https://project.pages.drupalcode.org/canvas/headless/setup/ .

Outline of Setup Steps

  • Create a folder for the project and cd into it.
  • Configure DDEV for Drupal with some extra modules needed for the Canvas Headless (canvas_headless) module
  • Create a folder to store OAuth keys.
  • Install the Haven recipe
  • Disable the Trash module because of a weird bug. There be dragons if you leave it enabled.
  • Enable the Canvas Headless and the Canvas OAuth modules
  • Log in with Chrome over http - the docs say to use Chrome and http.
  • Scaffold the Canvas Headless code, in a new folder called headless, with support for Next.js
  • Get Vercel AI skills to help your agents understand the Next/React conventions.
  • Install Canvas CLI
  • Start the Canvas Headless server.
  • Generate OAuth keys
  • Setup a consumer
  • Add the Frontend in the Canvas editor
  • Login with OAuth using Canvas CLI

Detailed Setup Steps

cd ~/Sites
mkdir headless
cd headless


ddev config --project-type=drupal11 --docroot=web
ddev start

ddev composer create-project drupal/recommended-project
ddev composer require --dev 'drush/drush'
ddev composer require 'drupal/haven' 'drupal/canvas' 'drupal/consumers' 'drupal/custom_elements' 'drupal/simple_oauth'

ddev restart

mkdir keys
ddev drush si -y recipes/haven
ddev drush un trash -y
ddev drush en canvas_headless, canvas_oauth -y
open -a "Google Chrome" $(ddev drush uli | sed 's/https:/http:/')

npx @drupal-canvas/create@latest headless \
  --template nextjs \
  --site-url https://headless.ddev.site \
  --agents none

cd headless
npx skills add vercel-labs/agent-skills --yes
npm install @drupal-canvas/cli
npm run dev

Open https://headless.ddev.site/admin/config/people/simple_oauth and click "Generate keys" button, then enter the folder that was created in the steps above:

/var/www/html/keys

Open http://headless.ddev.site/admin/config/services/consumer and click "+ Add Consumer", then set the following field values:

  • Label: Code Components
  • Client ID: code-components
  • Grant types (enable both):
    • JWT bearer (preview assertion)
    • Authorization Code
  • Authorization Code settings
    • Enable all scopes
    • Enable "Automatic authorization", "Remember previous approval", "Use PKCE?"
    • Redirect URIs: http://localhost:4444/callback

Open the Canvas editor and click the icon in the left rail for "Headless frontends" and click "Add frontend". For the Frontend URL field, use the following (no trailing slash, no query, and no fragment):

http://localhost:3000

If everything went as expected, the "Frontends" section will show http://localhost:3000 as being Ready.

Change the default OS browser to Chrome; the Canvas CLI login command will open a browser and it needs to be the browser you are developing in, which in this case needs to be Chrome.

In a new terminal window (the original one should still have the Node server running), use Canvas CLI to login. Make sure to cd into the headless folder in the directory of your site. In this example, the site and the folder are both named headless.

cd ~/Sites/headless/headless
npx canvas login

That will open a browser window to a link on your site, which redirects you to a localhost page that shows you a success/failure message. If everything went well, you can now use npx canvas to push and pull components from Drupal Canvas.

Notes

The example above doesn't use Astro, but if you do use Astro:

npx astro telemetry disable
